# Project instructions

- Ideas move through `ideas/inbox/` → `ideas/active/` → `ideas/done/` (or `ideas/parked/`). See `ideas/PROCESS.md`.
- When building an idea, read its brief in `ideas/active/` first. Build only your piece.
- One branch and one PR per thread. Don't edit files another piece owns.
- If you need something from the owner (settings, keys, accounts), ask once, clearly, and keep going on everything else.
- The owner is learning Python and SQL: prefer plain, readable code with short comments over clever code.
